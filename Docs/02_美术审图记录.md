## 2026-10-25 拓扑严查 + 场景动态化 + 万圣节符号强化

用户反馈：模型必须严格查拓扑（不得有结构错误、漏面、破面）；场景必须是动态的；万圣节元素要一眼看清。

**拓扑管线（所有模型强制）**
1. Tripo 模型：`Tools/repair_all.sh [名称...]` → `Tools/blender_repair.py`（向内 Solidify → 体素重建 → 去碎屑 → 减面 → 清理/兜底补洞 → 删拉丝面 → 烘焙原贴图），产出 `ArtSource/Models/<名>/repaired.glb`，不封闭则退出码 2。
2. `Tools/spike_check.py` 对比原模型：包围盒增长 <1.5%、远离原表面顶点≈0（排查体素化长出的尖刺/拉丝）。
3. `Tools/process_all.py` 优先用 repaired.glb 出 LOD0/1/2。
4. 程序化模型（Sanctum、Deco）：导出前三角化；导出后 `Tools/fbx_roundtrip_fix.py` 导入复查并修到 0 问题边。
5. 最终 `Tools/proc_audit.py` 对 Assets 下全部 FBX 审计：边界边/非流形/零面积/翻转面全为 0。当前 118/118 通过。
6. `Tools/render_compare.py` 原/修复四向对比图人工复看。
已修掉的历史问题：岛底岩块互相穿插+顶穿地面（改体素合并）、根须/绳索开口（封口）、拱券顶点重复、旧环廊石构（未使用，已删）、Tripo 全部开放边界与翻转面。

## 2026-10-26 场景 v4：客观审查后的修正

审查发现（多角度截图 + 实测包围盒）：环廊柱子立在岛外悬空（岛半径 4.6、柱子 6.2）；鬼脸树/墓园探出岛沿；卫星岛建筑陷进岩体 2–3 米；6 座吊桥指向空处、桥柱摆在地面中央；石板顶面高出规则层地面 ~10cm；骷髅烛台占桌面、糖果堆挡在敌人爬桌路线上；正前方柱子/旗串/蛛网挡玫瑰窗；月亮是方形面片且没对准窗心；烛海、星月地毯、钟楼未放；桌面调试相机朝后；玫瑰窗侧面朝玩家。

修正：
- 中心岛放大到 R=7.4（`blender_sanctum.py` 参数化），护边在正前方降为矮沿、4 个桥头开缺口；整岛下移 0.095 让石板面 = 规则层 y=0；新增 `Sanctum_Rug`（星月纹地毯，三材质槽，发光纹）。
- 环廊 8 根柱子立在 R=6.6，避开正前方 ±40° 与桥头；蝙蝠灯笼、旗串、蛛网都按柱子实际位置挂；正前方缺口不挂任何东西。
- 4 座吊桥（方位 ±62°、±128°，长 5.6 米）用向量对齐（`FromToRotation`），内端搭岛面、外端搭卫星岛沿；对应 鬼屋 / 墓园 / 女巫小屋 / 钟楼；3 座远景浮岛（书塔、稻草人南瓜田、墓碑）漂浮。
- `L7_FloatIsland` 原模型顶面倾斜 11°，用 `Tools/level_top.py` 迭代拟合平面调平到 0.35°；建筑按岛中心实际表面高度落座。
- 装饰全部用 `Decor()` 摆放，自动检查与敌人路线（桥头→最近桌腿）的地面净空，太近会报警告（当前 0 警告）。桌面只留玩法物件。
- 新月亮着色器 `MoonDisc`（软边圆盘+月海+光晕），沿“眼睛→窗心”延长线放在 85 米处，盘面比窗大一圈形成背光；天空 `_MoonDir` 同步。
- 浮空烛海 120 支（`CandleSea` 统一驱动浮动、火焰闪烁、天亮逐一熄灭）。
- 方位约定：`Bearing(deg, dist)`，0 = 正前 -Z、正值 = +X。Blender→Unity：Unity (x,z) = Blender (-x,-y)。
- 当前可见三角面约 74 万、实时点光 22 盏（PICO 真机需要减，见待办）。
